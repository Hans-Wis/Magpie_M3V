2A. Claude RV32 Report 補充項

RV32_report.pdf 的關鍵價值是把「跑過測試」提升成完整驗證論證。Magpie_M1 應採用其中的 layered evidence：riscv-arch-test、Spike lockstep、directed/self-check、Google RISC-V DV、benchmark correctness、coverage closure、formal、bug taxonomy、reproduction commands 與 FPGA-based PPA evaluation。Line coverage 目標為 100%；未達 100% 時必須逐項列出未覆蓋原因、可達性、補測計畫或 waiver。

8. 客戶合格 Checklist

  • ISA support matrix 已列出 RV32I、M、Zicsr 支援與 C/A roadmap 排除項。
  • Legacy note: ADR-0001 已由 ADR-0002 supersede for implementation。
  • Verilator lint/sim regression 可一鍵重跑，log 已歸檔。
  • 每個 directed ISA group 都有 PASS log 與可檢查 commit trace。
  • Spike per-commit lockstep 可定位第一筆 mismatch。
  • Google RISC-V DV constrained random seed archive 可重現。
  • Stretch items：arch-test、formal、CoreMark、C/A、FPGA-PPA 不阻塞 v1，除非另開 ADR 提升 scope。
  • CSR/trap/interrupt tests 覆蓋 entry、mret、illegal access、timing corner。
  • Pipeline hazard、forwarding、flush、wrong-path suppression 對 v1 multi-cycle FSM 標為 not-applicable；導入 pipeline 時另開 ADR/gates。
  • Line coverage 達 100%；若未達 100%，每個 uncovered line 都有原因、可達性、補測計畫或 waiver。
  • Functional / toggle coverage 達標或 waiver 已簽核。
  • Spyglass critical/high issues 為 0 或具名 waiver。
  • 每個 phase 都有短版 VCD excerpt，可看出該 gate 的關鍵行為。
  • Spyglass waiver 連到 phase、design intent 與對應 DV evidence。
  • Bug taxonomy 已列出 found-by layer、fix 與 regression gate。
  • Coverage residual analysis 已列出 line coverage 未達 100% 的原因，並區分 reachable gap 與 structural/environment-limited gap。
  • AI Design IDE 中可看到 RTL hierarchy、gate matrix、VCD、report 與 open risk。
  • FPGA-based PPA evaluation 已列出 LUT/FF/BRAM/DSP、timing/Fmax、optional power 與 regression delta。
  • 最終 handoff pack 包含 spec、RTL、DV、coverage、waiver、re-run commands。
