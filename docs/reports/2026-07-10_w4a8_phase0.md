## 2. 精度模擬 —— 合成權重無法給出 Go(方法論結論,非 No-Go)

| scheme | 權重 SNR | 單層輸出 SNR / cos | 18 層鏈 SNR / cos |
|---|---|---|---|
| int8 per-tensor | ~39 dB | 34.4 dB / 0.99982 | 26.0 dB / 0.99874 |
| w4 per-tensor | ~13.8 dB | 9.6 dB / 0.9448 | 3.2 dB / 0.760 |
| **w4 g=64** | **~19.4 dB** | 14.9 dB / 0.9839 | 7.3 dB / 0.907 |
| w4 g=32 | ~20.3 dB | 15.8 dB / 0.9870 | 8.2 dB / 0.924 |

**判讀(重要,不可直接當 No-Go)**:
1. iid Gaussian 是 **grouping 增益的最壞情境**(各 group max 幾乎相同 → 分組
   幾乎不幫);19–20 dB 就是 int4 在 Gaussian 上的資訊理論上限,量測符合理論
   = 模擬器本身正確。
2. **隨機權重網路的鏈式 cosine 不是 PPL 的有效代理**:真訓練後的網路對權重
   噪聲有冗餘/魯棒性,隨機矩陣鏈沒有。W4 g=64/128 在業界 ≥3B 模型 PTQ 成立
   (~19 dB 權重 SNR 即夠)靠的是模型功能魯棒性,不是更高 SNR。
3. **真風險點**:270M 級小模型冗餘少,W4 掉分比大模型明顯 —— 這正是合成模擬
   無法回答、必須真權重才能定案的部分。

## 3. Go/No-Go 判定

- **吞吐:GO**(§1,W4 是 50 tok/s 級的必要成分)。
- **精度:合成模擬不可判**(§2 方法論);Grok 原判準「L2 可接受→Phase 1」的
  L2 需 **真權重評估**(HF gemma-3-270m + 小型 PPL/logit-KL harness,~550MB
  下載,User 裁示)。
- **建議:條件式 GO** —— Phase-1 的**格式 SSOT 與架構確認先行**(g 做成
  32/64 可配置,成本近零),**RTL 動工前**完成真權重 L2;若真權重 g=64 掉分
  超標 → g=32 → 仍超標則按 Grok 決策樹轉 residency/x32。

## 4. 誠實界

合成 Gaussian 權重(缺真實 outlier 結構);A8 activation 量化誤差未疊加(W4
單獨歸因);無 KV/embedding 量化;PPL 未測;chained 實驗用獨立隨機層。全部
數字 `gate_96` 一鍵重現。
