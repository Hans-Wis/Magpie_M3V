4. Evidence Rules

Every development gate needs Verilator sim, code coverage, smoke/gate tests, Python/pytest checks, state JSON, and residual risk notes unless explicitly not-applicable. Pipeline hazard/forwarding/flush gates are not-applicable for multi-cycle v1.
AreaRule
CoverageLine coverage target is 100%; uncovered lines require reason, reachability, closure plan or waiver. Toggle >= 85%, functional >= 95% unless waived.
DVDirected tests close intent first. Spike is the reference for lockstep/first-fail triage. Google RISC-V DV runs after deterministic directed flow is stable.
FPGA/PPAOptional evaluation track: LUT/FF/BRAM/DSP, WNS/TNS/Fmax, optional power, regression deltas. It does not replace functional sign-off.
